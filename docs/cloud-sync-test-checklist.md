# Mitru クラウド同期テストチェックリスト

対象バージョン: `v0.9.7-beta`

このチェックリストは、クラウド同期をOFFのまま使う場合と、Bring Your Own Supabase方式でONにする場合の両方を確認するための手順です。同期テスト前には必ず「アプリ設定 > データ出力」からバックアップを作成してください。

## 1. クラウド同期OFFの確認

- [ ] アプリ設定を開いても、Supabaseログインを要求されない
- [ ] クラウド同期トグルがOFFのままでも、案件作成、積算、見積、請求、入金、レポートが使える
- [ ] 「全データ同期」を押した場合、クラウド同期が無効である旨が表示され、ローカルデータが壊れない
- [ ] サイドバー遷移、PDF出力、データ出力に影響がない

## 2. Supabase接続設定

- [ ] 「アプリ設定 > クラウド同期」を開く
- [ ] Supabase Project URL を入力できる
- [ ] Supabase Anon Key を入力できる
- [ ] 「接続テスト」成功時に接続成功表示になる
- [ ] URLまたはKeyが誤っている場合、わかりやすいエラーメッセージが表示される
- [ ] Supabase URL / Anon Key が空欄でも、他の画面は通常通り使える

## 3. 認証フロー

- [ ] クラウド同期トグルをONにするとログインモーダルが表示される
- [ ] メールアドレスとパスワードでログインできる
- [ ] ログイン失敗時に優しいエラーメッセージが表示される
- [ ] 「後でする」を選んでも、オフライン機能は通常通り使える
- [ ] ログイン成功後、認証状態が「認証済み」になる
- [ ] 未同期状態でログインした場合、初回同期確認ダイアログが表示される

## 4. 主要フロー同期テスト

1. 案件作成
   - [ ] 新規案件を作成する
   - [ ] 案件No.、顧客、工事場所、ステータスが保存される

2. 積算
   - [ ] 工事項目または材料を追加する
   - [ ] 数量、単価、小計、粗利表示が崩れない

3. 見積
   - [ ] 見積書を作成する
   - [ ] 見積書のスナップショットが保持される

4. 請求
   - [ ] 請求書を作成する
   - [ ] 請求書のスナップショットが保持される

5. 入金
   - [ ] 入金登録を行う
   - [ ] 未入金、一部入金、入金済、過入金の表示が正しい

6. 同期
   - [ ] 「全データ同期」を実行する
   - [ ] 進捗が案件→顧客→見積書→請求書→入金記録の順に表示される
   - [ ] 同期履歴に直近結果が記録される
   - [ ] 一部失敗時も、成功した部分とローカルデータが保持される

## 5. 同期ON/OFF切り替え

- [ ] 同期ON後にOFFへ戻しても、ローカルデータが消えない
- [ ] OFF状態では認証や同期が自動実行されない
- [ ] 再度ONにしたとき、保存済みの接続情報と認証状態が安全に復元される

## 6. 大量データ時の確認

- [ ] 案件100件以上の状態で設定画面が固まらない
- [ ] 「全データ同期」開始時に進捗表示が出る
- [ ] 同期失敗時にErrorBoundaryへ落ちない
- [ ] 同期履歴が直近3件に整理される

## 7. ベータ公開前の注意

- [ ] Supabase側のテーブル作成SQLとRLS設定が配布案内に明記されている
- [ ] 実案件同期前のバックアップ推奨をユーザーに案内している
- [ ] 複数端末で同じデータを同時編集する場合の注意事項を案内している
- [ ] クラウド同期はベータ機能であることを明記している
