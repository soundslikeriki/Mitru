# Phase 3 書類作成・案件進行管理 総合テストチェックリスト

## 1. 書類レイアウト共通確認

- [ ] 見積書、請求書、納品書、注文書のA4プレビューでタイトル位置、発行情報、ロゴ、社判の位置が大きく崩れていない
- [ ] 4種類の帳票でフォントサイズ、余白、明細テーブルの列幅が揃っている
- [ ] 明細の工事項目が `【大工区】 中項目 / 細目` の形式で表示される
- [ ] 長い工事項目名、品番・仕様、備考が枠外へ見切れない
- [ ] 10項目を超える明細で複数ページに分割され、ページ番号が正しく表示される
- [ ] 最終ページに合計、備考、会社情報、社判が自然に表示される

## 2. 書類作成フロー

- [ ] 積算タブから見積書を作成でき、見積書一覧に即時反映される
- [ ] 見積書から請求書を作成でき、請求書一覧に即時反映される
- [ ] 案件詳細ヘッダーから納品書を作成でき、納品書一覧に即時反映される
- [ ] 案件詳細ヘッダーから注文書を作成でき、注文書一覧に即時反映される
- [ ] 納品書・注文書のプレビューボタンで社判・ロゴ編集付きの印刷プレビューが開く
- [ ] 納品書・注文書のPDF出力ボタンでPDF保存処理が起動する
- [ ] 各一覧の削除ボタンで確認後に対象書類が削除される

## 3. 案件進行管理

- [ ] 案件詳細に `進行管理` タブが表示される
- [ ] ステータス変更時に確認ダイアログが表示される
- [ ] ステータス変更後、案件一覧とダッシュボードに即時反映される
- [ ] 次回対応日、工程メモ、担当者メモが保存される
- [ ] メモ欄は500文字で制限され、文字数カウンターが表示される
- [ ] 見積書、請求書、納品書、注文書の件数とステータスが書類進捗一覧に表示される
- [ ] 請求書がすべて入金済の場合、`請求済` への更新提案が表示される
- [ ] 納品書が発行済または納品済で案件が施工中の場合、`完了` への更新提案が表示される

## 4. ダッシュボード・案件一覧連携

- [ ] ダッシュボードに `次回対応が近い案件` セクションが表示される
- [ ] 次回対応カードをクリックすると該当案件の進行管理タブへ遷移する
- [ ] 案件一覧に `次回対応` 列が表示される
- [ ] 期限超過、要確認、予定済みの色分けが自然に表示される
- [ ] 粗利率50%未満、55%未満の警告が既存の利益表示と矛盾しない

## 5. 回帰確認

- [ ] 案件基本情報の保存が引き続き動作する
- [ ] 積算テーブルの編集、クイック追加、テンプレート保存が引き続き動作する
- [ ] 見積書・請求書の既存プレビュー/PDF出力が引き続き動作する
- [ ] localStorageを保持したまま再読み込みしても既存案件が表示される
- [ ] `npm run build` が成功する
