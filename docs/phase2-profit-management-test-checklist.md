# Phase 2 利益予実管理・ダッシュボード 手動テストチェックリスト

## 利益予実管理
- [ ] 案件詳細の概要/積算まわりで「利益予実管理」セクションが表示される
- [ ] 予定（見積）粗利、実行粗利、差額・差率が表示される
- [ ] 実材料費、実労務費、外注費を入力すると実行粗利と粗利率が即時更新される
- [ ] 粗利率70%以上は緑、50〜70%は黄、50%未満は赤で表示される
- [ ] 粗利率50%未満の明細行が赤く強調される
- [ ] 案件全体の粗利警告が出た場合、警告アイコンとメッセージが読みやすい

## 案件一覧
- [ ] 案件一覧に予定粗利、実行粗利、粗利率、リスクレベルが表示される
- [ ] 粗利率の色分けが70%以上緑、50〜70%黄、50%未満赤で統一されている
- [ ] 「粗利50%未満」フィルターでリスク案件だけに絞り込める
- [ ] 並び替えで「粗利率が高い順」「危険度順」が動作する
- [ ] 「予実 入力」から該当案件の確認画面へ遷移できる

## ダッシュボード全体
- [ ] 上部KPIに今月の予想売上、今年の累計粗利、平均粗利率、赤字リスク案件数が表示される
- [ ] 「今年の業績予測」に今年の予想売上、今年の予想粗利、平均粗利率、前年比が表示される
- [ ] 目標に対する達成率のバーが売上・粗利の両方で表示される
- [ ] 月別・四半期別の内訳が表示され、粗利率トレンドの色分けが他画面と一致する
- [ ] 年間粗利率が60%未満の場合、注意メッセージが表示される
- [ ] 「キャッシュフロー予測」に3ヶ月の入金予定、支出予定、累計キャッシュが表示される
- [ ] 翌月キャッシュがマイナス見込みの場合、赤い警告が表示される
- [ ] 「リスク案件」カードに粗利率50%未満の案件が表示され、クリックで積算タブへ移動できる

## レスポンシブ確認
- [ ] 1280px幅で「今年の業績予測」「キャッシュフロー予測」「最近の案件」「リスク案件」の配置が窮屈でない
- [ ] タブレット幅で各カードが縦に自然に並ぶ
- [ ] モバイル幅でKPIカード、予測カード、リスク案件カードの文字が見切れない
- [ ] 横スクロールが必要な表でも、主要な情報が読める

## 数字・説明表示
- [ ] ダッシュボードの大きな金額は万円/億円単位で読みやすく表示される
- [ ] 小さい金額や差額もカンマ区切りで読める
- [ ] 今年の業績予測カードにマウスを乗せると計算根拠の説明が確認できる
- [ ] 帳票や一覧の円表記に不要な影響が出ていない
