# Phase 1 積算エンジン 手動テストチェックリスト

## 基本表示
- [ ] 案件詳細の積算タブを開いて、上部に「利益を見ながら積算する」パネルが表示される
- [ ] クイック追加、テンプレート、積算テーブル、積算合計が画面幅に応じて崩れず表示される
- [ ] タブレット幅でも横スクロールで積算テーブル全体を確認できる

## クイック追加
- [ ] 大工区フィルターで表示項目が絞り込まれる
- [ ] 「すべて」「お気に入りのみ」「最近使用」「マスタ検索」が切り替わる
- [ ] 単体追加で積算テーブルに行が追加され、追加行へスクロール・フォーカスされる
- [ ] 複数選択して一括追加できる

## 単価・歩掛
- [ ] マスタから追加した行に見積単価、原価単価、見積労務単価、実行労務単価が入る
- [ ] 数量を変更すると労務費、小計、粗利率が即時更新される
- [ ] 見積歩掛・実行歩掛を変更すると人工表示が更新される
- [ ] 歩掛クイック選択ボタンで見積歩掛・実行歩掛が同時に更新される
- [ ] 「最新マスタ価格に更新」で確認ダイアログが表示され、更新後に単価が反映される

## 利益表示
- [ ] 粗利率70%以上は緑、50〜70%は黄、50%未満は赤で表示される
- [ ] 各行、階層小計、総合計の粗利表示に色分けが適用される
- [ ] 見積粗利と実行粗利の差額・差率が更新される
- [ ] 前回単価がある行では差額・差率が表示される

## テンプレート
- [ ] Ctrl / Command + S で積算テンプレート画面が開く
- [ ] テンプレート名を入力して現在の積算を保存できる
- [ ] 保存済みテンプレートを読み込むと、階層を保ったまま一括追加される
- [ ] テンプレートと現在のマスタ単価に差がある場合、差分が色付きで表示される
- [ ] テンプレートを削除できる

## 帳票連携
- [ ] 積算タブで変更した数量・単価・歩掛が見積書タブの明細に反映される
- [ ] 請求書タブでも積算明細が崩れず表示される
- [ ] PDF/印刷プレビューで品番・仕様、数量、単価、金額が自然に表示される
